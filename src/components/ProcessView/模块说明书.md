# ProcessView 模块说明书

## 1. 模块概述
ProcessView 模块是流程图展示与编辑的核心组件，面向项目管理平台中的流程可视化需求，基于 Cytoscape.js 完成节点/边的布局、渲染与交互，辅以 Ant Design 的菜单交互以及自定义曲线计算与跨区间连线逻辑。模块同时提供只读模式与编辑模式（带悬浮菜单与连线操作），支持流程节点状态展示、节点点击、边新增/删除与节点新增/删除等操作约束。

## 2. 功能边界与职责
- **流程图渲染**：将流程节点数组解析为 Cytoscape 元素，负责节点/边的生成与样式绘制。
- **布局与曲线计算**：在层级（layer）与纵向序（y order）基础上进行位置计算，使用预计算的贝塞尔曲率实现边的美观绘制。
- **跨区间连线**：通过虚拟节点实现跨层连线的可视化，保证连接路径规范且结构稳定。
- **交互能力**：支持节点点击、悬浮菜单、连线新增、边删除与节点删除等行为（含约束校验）。
- **状态显示**：节点根据状态展示不同颜色标识，支持进行中、已完成与未开始。

## 3. 运行环境与依赖
- **React**：组件结构与生命周期管理。
- **Cytoscape.js**：流程图渲染引擎。
- **cytoscape-edgehandles**：绘制连线的交互扩展（编辑模式）。
- **cytoscape-popper** + **floating-ui**：节点悬浮菜单定位。
- **Ant Design**：节点操作菜单 UI。
- **lodash-es**：深拷贝与防抖处理。

## 4. 数据结构设计
### 4.1 节点结构
```ts
interface ProcessNodeType {
  id: string | number
  name: string
  visible: boolean
  relativeDuty?: string
  status: 'pending' | 'in_progress' | 'completed'
  canDelete: boolean
  canUndo: boolean
  prevNodes: (string | number)[]
  nextNodes: (string | number)[]
  speicalMark?: 'startNode' | string
  type?: string
}
```

### 4.2 虚拟节点结构
```ts
interface ProcessVirtualNodeType {
  type: 'virtual_node'
  id: string | number
  prevNodes: (string | number)[]
  nextNodes: (string | number)[]
}
```

### 4.3 边曲率样式
通过预计算映射表 `PRECOMPUTED_CURVATURE_STYLES` 生成曲率样式，键为  
`${leftTotal}-${leftIndex}-${rightTotal}-${rightIndex}`，用于快速查找贝塞尔曲线控制点参数。

## 5. 绘图流程描述
### 5.1 流程图生成总体流程
1. **输入节点数组**（包含前继/后继关系）。
2. **构建节点映射**（id -> node），统一 id 为字符串。
3. **层级与纵向序计算**：从起点深度遍历，生成 `nodeLayerMap` 与 `nodeYAxisOrderMap`。
4. **跨区间边处理**：识别跨层连接并引入虚拟节点，更新映射与连接关系。
5. **节点位置计算**：按层级与序号计算坐标 `(x, y)`。
6. **边构造与曲线样式**：按相邻区间的连线规则生成边并赋予曲线参数。
7. **渲染输出**：将节点与边组装为 Cytoscape elements 并渲染。

### 5.2 跨区间连线流程
1. 汇总所有跨层边。
2. 以起点为键收集终点数组，计算终点平均 y。
3. 根据起终点高低关系确定虚拟节点走向（up/down）。
4. 为每一层生成虚拟节点，按照路径连接起点、虚拟节点与终点。
5. 清理原始跨层直连，保持图结构一致。

### 5.3 边曲率计算流程
1. 计算左右侧节点数量与索引位置。
2. 判断左右侧单双数对齐情况：
   - 对齐：采用 `curveCaleWithAlign`。
   - 不对齐：采用 `curveCaleWithoutAlign`。
3. 返回曲线控制点距离与权重，实现视觉均衡。

## 6. 交互流程设计
### 6.1 节点点击
- 点击节点选中并触发 `onNodeClick` 回调。
- 节点样式高亮显示选中与悬浮状态。

### 6.2 悬浮菜单与节点操作
- 鼠标悬浮时显示菜单按钮。
- 支持添加节点、连接节点、删除节点与断开连接。
- 菜单内容基于当前节点与全量节点动态生成。

### 6.3 连线新增
- 在编辑模式下，鼠标拖拽触发连线逻辑。
- 校验是否形成环；若形成环则拒绝并提示错误。

### 6.4 删除边与删除节点
详见“详细设计总结”，严格校验关键路径与连通性。

## 7. 关键算法与约束设计
### 7.1 删除节点约束
- 不允许删除唯一的开始节点。
- 前继节点数 + 后继节点数 > 6 时拒绝删除。
- 删除后前继与后继节点重新连接，保持流程连通性。

### 7.2 删除边约束
- 删除后必须保证后继节点仍可从开始节点到达。
- 采用 BFS/DFS 检查可达性，若不可达则拒绝删除。

### 7.3 新增边约束
- 禁止形成环；使用 DFS 递归检测。
- 若存在环则抛出 `CycleDetectedError`。

## 8. 详细设计总结
### 8.1 核心模块划分
- **`index.tsx`**：流程图渲染与交互主入口（编辑/只读两种模式）。
- **`utils.ts`**：节点/边增删、布局计算、曲率计算与跨区间虚拟节点处理。
- **`NodeClickMenu.tsx`**：节点操作菜单生成与展示。
- **`popperContainer.ts`**：菜单容器 DOM 管理与显示控制。
- **`types.ts`**：节点与流程图核心类型定义。
- **`MeasureTextLength.ts`**：基于 Canvas 的文本宽度测量，决定节点宽度。
- **`errors.ts`**：流程图操作错误类型。

### 8.2 渲染与布局细节
- 节点宽度根据文本测量动态调整，提升可读性。
- 采用层级与序号的布局方法保证流程从左到右、从上到下的有序性。
- 曲线边采用预计算样式映射，保证性能与一致性。

### 8.3 交互与状态细节
- 节点状态使用圆点颜色标识（未开始/进行中/已完成）。
- 编辑模式下支持快速连线、菜单操作，提升流程建模效率。
- 所有修改操作均有约束校验，保证流程结构的正确性。

## 9. 可扩展性与改进建议
- 可进一步实现 `ProcessManager` 的节点增删改与职责过滤逻辑，使流程图支持“职责视角”动态展示。
- 可在跨区间连线时优化路径选择，减少绕行，提高视觉紧凑度。
- 可补充节点/边的序列化与版本控制机制，支撑流程历史回滚。

## 10. 小结
ProcessView 模块以“可视化正确性 + 交互可用性 + 结构安全性”为设计原则，通过层级布局、曲线样式预计算与严格约束校验，实现稳定的流程图呈现与编辑能力。模块可作为项目管理平台中的核心流程展示组件，并为后续扩展提供良好的工程基础。
